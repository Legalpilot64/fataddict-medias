# fataddict-medias

Les vidéos publiées par [FATADDICT](https://www.tiktok.com/@fataddict.fr).

Ce dépôt est public **uniquement pour être servi par jsDelivr** : l'API Instagram
Reels exige une URL publique renvoyant `video/mp4`, ce que `raw.githubusercontent`
ne fait pas (il renvoie `application/octet-stream`).

Chaque fichier est déjà diffusé publiquement sur TikTok et Instagram le jour de sa
date. Aucun code, aucune donnée, aucun secret ici.

```
https://cdn.jsdelivr.net/gh/Legalpilot64/fataddict-medias@main/videos/AAAA-MM-JJ.mp4
```

Les vidéos comportent des images générées par IA (déclarées `is_aigc` à la
publication, conformément aux règles des plateformes et à l'AI Act art. 50).
